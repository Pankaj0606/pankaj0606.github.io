# ⚡ Pankaj Yadav — Personal Engineering Portfolio

A modern, high-contrast monochromatic portfolio website featuring **liquid glassmorphism modals**, an **interactive developer CLI terminal**, and a signature **circular view-transition dark/light theme switch**.

Live Website: **[https://pankaj0606.github.io](https://pankaj0606.github.io)**

---

## ✨ Key Features & UX Highlights

- **Circular View-Transition Theme Switch:** Fluid radial clip-path animation expanding from the toggle button coordinates (Recent.design style).
- **Liquid Glass Bento Grid:** 9 featured production repositories with live status indicators, tech pills, and blurred specular glass overlays.
- **Embedded Interactive Terminal:** In-browser developer shell with custom commands (`projects`, `skills`, `about`, `contact`, `theme`).
- **Zero-Dependency Architecture:** Engineered purely in modern HTML5, CSS3 Custom Properties, and Vanilla JavaScript with fast loading times and zero build steps.
